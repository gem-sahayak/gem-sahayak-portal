# ASTRA Reasoning Guide (v1.11.0)

Welcome to **ASTRA Autonomous Reasoning Engine**, evaluating repository facts, system constraints, evidence items, and confidence metrics.

## CLI Commands
```bash
# Run Reasoning Engine
node cli.js reason

# Specific Options
node cli.js reason --analyze
node cli.js reason --trace
node cli.js reason --facts
node cli.js reason --constraints
node cli.js reason --confidence
```
