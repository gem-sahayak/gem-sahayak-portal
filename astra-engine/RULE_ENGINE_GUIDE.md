# ASTRA Rule Engine Guide (v1.9.0)

Welcome to **ASTRA Rule Engine**, providing condition parsing, boolean expression evaluation, priority rule compiling, and action planning.

## Features
- **Condition Parsing:** Parses boolean expressions (`score > 80`, `errors == 0`).
- **Expression Evaluation:** Safe offline condition evaluator without `eval()`.
- **Rule Action Planning:** Compiles and orders rule execution plans.
