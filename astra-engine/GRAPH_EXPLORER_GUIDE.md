# ASTRA Graph Explorer Guide (v1.8.0)

Welcome to **ASTRA Enterprise Visual Knowledge Graph Explorer**, the visual graph analytics layer for ASTRA Engine.

## CLI Commands
```bash
# Render Composite Visual Knowledge Graph
node cli.js graph

# Specific Graph Network Views & Analytics
node cli.js graph --entities
node cli.js graph --keywords
node cli.js graph --clusters
node cli.js graph --dependencies
node cli.js graph --plugins
node cli.js graph --metrics
node cli.js graph --orphans
node cli.js graph --pagerank
```
