# ASTRA Studio Foundation Guide (v1.7.0)

Welcome to **ASTRA Studio**, the enterprise visual AI workspace for ASTRA Engine.

## Keyboard Shortcuts
- `Ctrl+P`: Open Command Palette
- `Ctrl+Shift+R`: Open Reports Explorer
- `Ctrl+Shift+G`: Open Knowledge Graph Explorer
- `Ctrl+Shift+O`: Open Content Optimizer
- `Ctrl+Shift+K`: Open Knowledge Intelligence RAG Engine

## CLI Launch Commands
```bash
# Launch ASTRA Studio Workspace
node cli.js studio

# View Studio Settings
node cli.js studio --settings
```
