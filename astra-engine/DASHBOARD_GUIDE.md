# ASTRA Dashboard Guide (v1.7.1)

Welcome to **ASTRA Enterprise Intelligence Dashboard**, the visual analytics layer for ASTRA Engine.

## CLI Commands
```bash
# Render Full Intelligence Dashboard
node cli.js dashboard

# Specific Dashboard Views
node cli.js dashboard --overview
node cli.js dashboard --seo
node cli.js dashboard --review
node cli.js dashboard --semantic
node cli.js dashboard --optimizer
node cli.js dashboard --knowledge
node cli.js dashboard --performance
node cli.js dashboard --telemetry
```
