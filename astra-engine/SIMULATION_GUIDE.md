# ASTRA Simulation Guide (v1.10.0)

Welcome to **ASTRA Enterprise Simulation Intelligence Engine**, the dry-run sandbox and timeline replay platform for ASTRA Engine.

## CLI Commands
```bash
# Run Simulation Dry Run
node cli.js simulate

# Specific Options
node cli.js simulate --dry-run
node cli.js simulate --timeline
node cli.js simulate --replay
node cli.js simulate --history
```
