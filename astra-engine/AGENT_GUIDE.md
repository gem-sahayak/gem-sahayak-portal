# ASTRA Agent Guide (v1.12.0)

Welcome to **ASTRA Multi-Agent Engine**, registering, starting, stopping, and managing autonomous agent identities and lifecycles.

## CLI Commands
```bash
# Run Agent Engine
node cli.js agents

# Specific Options
node cli.js agents --list
node cli.js agents --status
node cli.js agents --health
node cli.js agents --memory
node cli.js agents --metrics
```
