# GeM Catalog Rejected Reasons: Brand Validation, Specifications & Rejected Alerts Fixes

Government e-Marketplace (GeM Portal) par apne products list karna kisi bhi seller ke liye public procurement tenders aur direct purchase orders access karne ka pehla aur sabse mahatvapurna step hai. Lekin, bahut baar jab sellers apna catalog upload karte hain, toh unhe dashboard par warning status aur **"Catalog Rejected"** ka message dikhta hai.

GeM Portal par uploaded products ka validation manual aur system-automated levels par hota hai. Jab bhi aap koi technical parameter galat daalte hain, copy-pasted images use karte hain, ya non-compliant documents upload karte hain, toh GeM administrative desk aapke request ko reject kar deta hai. GeM catalog rejection se na sirf aapka samay kharab hota hai balki aap bidding opportunities bhi miss kar sakte hain.

Is comprehensive guide me, hum GeM portal ke parameters ke latest rules, Brand validation processes, dynamic system checks, aur key rejection alerts ko step-by-step fix karne ka practical tarika Hinglish me samjhenge.

---

## ⚡ Quick Answer: GeM Catalog Rejections Kyu Hote Hain?

> **Quick Answer:** GeM Portal par catalog rejections mostly teen reasons se hote hain: 1) **Brand Validation Issues** (valid Brand Code ya OEM Authorization na hona), 2) **Incorrect Catalog Parameters** (restrictive or incorrect specifications enter karna), aur 3) **Image Quality Errors** (watermarked, blurry, ya copy-pasted images). Inhe fix karne ke liye aapko dashboard par diye gaye Rejection Code ke aur verification status ke rules ko correct karke resubmit karna padta hai.

GeM portal par business grow karne ke liye catalog upload hi aapka pathway hai. GFR 2017 Rule 149 ke tehat public buyers ko direct procurement ya bidding ke liye portal catalog data ka transparent validation check verify karna padta hai.

Bahut se sellers warning alerts ignore kar dete hain, jiske chalte unka catalog direct administration block list me chala jata hai. Rejections avoid karne ke liye system specs ko generic rakhna aur documentation standards maintain karna compulsory hai.

## 📋 Prerequisites

Before fixing a catalog rejection, make sure you have:
1. **Active GeM Seller Account:** Portal dashboard par active log-in permissions honi chahiye.
2. **Access to Rejection Remarks:** Seller panel me 'Catalogue' -> 'Search/Manage Products' par jaakar "Reject Remarks" dekhne ki clarity.
3. **Trademark Registration Document:** Valid class certificate (agar aap brand owner/OEM hain).
4. **Digital copies of OEM MAF:** Authorized resellers ke liye updated digital copy ready honi chahiye.
5. **High-quality product images:** Minimum 3 unique views, pure white background (RGB 255, 255, 255), aur zero editing text overlays.

---

## 📄 Required Documents Checklist

- [ ] **Trademark Registry Certificate (Class wise):** Brand registration request verify karne ke liye (PDF, Max 2MB).
- [ ] **OEM Authorization Letter / MAF:** OEM-signed letterhead par specific date aur model numbers ke details ke sath (PDF).
- [ ] **Product Specification Leaflet / Datasheet:** Manufacturer-approved technical datasheet (TDS).
- [ ] **BIS / NABL Test Reports:** Regulatory criteria requirements certification compliance validation ke liye.
- [ ] **Original Product Images:** Min 3 high-resolution angles, without any watermarks or overlays.

## 🛠️ Step-by-Step Guide to Resolving Catalog Rejection

Niche diye gaye system step-by-step workflow ke mutabik rejected catalog update karein:

### Step 1: Analyze the Rejection Code and Admin Remarks
GeM Seller Dashboard par login karein. Navigate to **Catalogue -> Products -> Search/Manage Products**. Check for listings under 'Rejected' status. Yahan click karke detailed **Rejection Code** aur Admin instructions note karein (jaise *RC01 (Brand Not Mapped)* ya *RC08 (Poor Image)*).

### Step 2: Fix Brand Validation & Code Issues
Agar error code brand registration se relate karta hai:
* **For OEMs:** "My Brand" request raise karein aur Class Certificate upload karein. Make sure trademark status IP India portal par "Registered" status se match karta ho.
* **For Resellers:** Apne OEM desk ko call karein aur unse request karein ki wo aapko Brand Code verification invite link share karein ya OEM panel par aapko add karein. Valid MAF upload karein.

### Step 3: Align Product Parameters (Remove Restrictive Specs)
Specifications ko verify karein:
* Specifications tab me, koi bhi brand-exclusive size or dimensions na likhein (e.g. don't write "Specialized HP 430 type design"). Use generic technical terms.
* Golden parameters aur details check karein taaki data, manufacturer datasheet PDF ke variables se 100% match kare.

### Step 4: Re-upload Clean Product Images
Images ko optimize karein:
* Apni product photos se logos, watermarks, frame borders, ya copy-pasted background textures remove karein.
* Only clean, high-resolution product photos select karein jinka background pure white ho (without shadows/blur).

### Step 5: Save & Resubmit
Edits complete karne ke baad **Save & Submit for Admin Review** par click karein. Review cycle standardly 3 to 7 working days me complete ho jata hai.

## ❓ Structured FAQs (15 Detailed Q&As)

### 1. GeM portal par Brand Code Validation issue kyu aata hai?
Jab aap kisi branded product ko list karte hain aur us brand ka code GeM database me mapped nahi hota, ya aapke account ke pass us brand ko sell karne ki authorization nahi hoti, tab portal "Brand Code Validation Error" show karta hai. Aapko Brand Request raise karke authorization submit karni hoti hai.

### 2. "Restrictive Parameter" rejection kya hai aur isse kaise bachein?
Jab product specifications me aap aisi specifications likhte hain jo market me kisi ek specific manufacturer ke model ko design-wise favor karti hain, toh use "Restrictive Parameter" bolte hain. Hamesha specification me generic parameters (jaise dimension, weight, capacity) use karein, specific design-parts ya brand terms nahi.

### 3. Product Image Quality rejection se kaise bachein?
GeM rules ke anusar product photos clear honi chahiye. Image background plain white hona chahiye. Image par koi text, company stamp, logo, ya watermark nahi hona chahiye. Multi-angle (minimum 3 angles) photos upload karein.

### 4. OEM Authorization Form (MAF) validation fail kyu hoti hai?
MAF tab fail hota hai jab document par signature clear nahi hote, validation date expire ho gayi hoti hai, ya fir authorization letter me authorized categories specific nahi hoti. Upload karne se pehle verify karein ki MAF latest dates aur OEM letterhead par ho.

### 5. GeM catalogue me "Abnormal Pricing Detected" alert kya hota hai?
Agar aapne product ka MRP ya offering price market dynamic values se 10% ya usse zyada set kiya hai, toh portal ka algorithm ise automatic price manipulation block me daal deta hai. Price ko reasonable market rate par edit karein.

### 6. Brand Link Request accept hone me kitna samay lagta hai?
Brand Link approval team general tickets ko 3 se 5 working days me verify kar leti hai, agar supporting documents (Trademark Class Certificate) valid hain.

### 7. Unbranded products ke liye catalog uploading rules kya hain?
Unbranded items ki listing ke liye "Generic" brand select karna padta hai. Isme system automated price filtering aur BIS/ISO certifications ko inspect karta hai. Rejection rates unbranded products me parameters ki discrepancies ke karan high hote hain.

### 8. "Specification Mismatch" reject criteria kya hai?
Jab aap technical datasheets (PDF) upload karte hain aur form me fill kiye gaye parameters (jaise 1000W) data sheet se match nahi karte, tab admin is catalog ko reject kar deta hai. Form parameters aur PDF attributes identical hone chahiye.

### 9. Kya main rejected catalog ko edit karke resubmit kar sakta hoon?
Haan, GeM portal par rejected listings me "Edit" button enabled hota hai. Remarks section ke errors ko update karke aur validation documents change karke aap product ko dobara review ke liye bhej sakte hain.

### 10. GeM catalog rejection codes ka status kahan show hota hai?
Aap dashboard par log-in karke Catalogue -> Products -> Search/Manage Products page par jaakar target listing ke "Status" check kar sakte hain, jahan click karne par detailed remark code dikhta hai.

### 11. HSN code issue ke karan catalog reject ho jaye toh kya karein?
Galat HSN ya GST percentage map karne se catalog system hold par chala jata hai. Direct tax department database se correct 8-digit HSN mapping choose karein aur pricing details refresh karein.

### 12. Image size aur format rules kya hain GeM catalog me?
JPEG ya PNG format support hota hai. Resolution minimum 500x500 pixels aur clear side angles hone zaroori hain. Product ka area image box ka minimal 75% cover karna chahiye.

### 13. "Duplicate Product Detected" error kaise solve karein?
Jab standard catalog database me bilkul wahi brand model pehle se available hota hai, tab system entry block kar deta hai. Check karein aur normal marketplace se exist brand category me add-product option search karein.

### 14. Kya OEM portal blacklist ho sakta hai invalid brand codes upload karne par?
Haan. Fake trademark documents ya expired authorization letters bar-bar submit karne par GeM security dashboard seller panel ko blacklisting block me bhej sakta hai.

### 15. Rejection errors se bachne ke liye expert tip kya hai?
Hamesha catalog upload karne se pehle related category ke active market listings ke technical data checklist ko benchmark karein aur specifications ko non-exclusive generic rakhein.
