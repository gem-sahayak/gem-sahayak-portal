# IREPS Railway Bidding Guide: Step-by-Step Contractor Registration (2026)

Indian Railways duniya ke sabse bade rail networks me se ek hai, aur har saal hazaron crore rupaye ke procurement contracts (works, goods, aur services) execute karta hai. Agar aap ek contractor, supply manufacturer, ya service provider hain jo Railways ke tenders me part lena chahte hain, toh aapko **Indian Railways e-Procurement System (IREPS)** ke bare me sab kuch pata hona chahiye.

Railways e-tenders ko manually ya kisi generic state portal par bid nahi kiya jata. Iske liye dedicated official portal **ireps.gov.in** ka use hota hai. Is guide me hum IREPS contractor registration, Class 3 Digital Signature Certificate (DSC) mapping, Java configuration settings, and online bid submission rules ko natural Hinglish me step-by-step samjhenge.

---

## ⚡ Quick Answer: IREPS Contractor Registration Kya Hai?

> **Quick Answer:** IREPS Contractor Registration ek online profile onboarding system hai jahan vendors aur civil/mechanical contractors Indian Railways ke central procurement portal (`ireps.gov.in`) par apna official firm account register karte hain. Portal par sign-in karne aur bids submit karne ke liye Class 3 DSC (Signing + Encryption) mandatory hai, aur registration bilkul free hota hai.

## 💡 Introduction

IREPS portal ko **CRIS (Centre for Railway Information Systems)** ne design aur manage kiya hai. GFR 2017 Rules aur Railway Board directives ke anusar, Indian Railways ke sabhi zonal units (जैसे North, East, West, South, Central Railways) aur production units (जैसे ICF, RCF, CLW, DLW) ke saare tender activities isi portal par host hote hain.

Kuch saal pehle tak, railways tenders paper-based envelope systems se hote the. Aaj ke digital era me 100% railway procurement online e-procurement through IREPS ho chuka hai. Isliye, agar aapko railways me goods supply karne hain ya railway track, building, signalling works lene hain, toh IREPS registration compulsory step hai.

## 📋 Prerequisites Before Registering on IREPS

IREPS par profile setup shuru karne se pehle ye technical setup completed hona chahiye:

1. **Class 3 DSC USB Token:** Standard digital signature certificate jisme signing aur encryption dono properties enabled hon.
2. **Java Run Time Environment (JRE):** Windows PC me Java 8 (Update 151 ya usse upar) install hona zaroori hai.
3. **Browser Setting:** Internet Explorer mode inside Microsoft Edge browser configuration (active active-x elements access ke liye).

## 📄 Required Documents Checklist

Vendor profile register karte waqt upload karne ke liye in documents ko scan karke PDF (Max 2MB per file) me save karein:

- [ ] **Firm PAN Card:** Proprietor ya business entity ka tax identification card.
- [ ] **GSTIN Document:** GST Registration certificate copy.
- [ ] **Active Bank Account Proof:** Bank Cancelled Cheque aur Passbook scan showing IFSC and MICR codes.
- [ ] **Authorized Signatory Letter:** Board Resolution ya authorization letter (agar multiple partners hain).
- [ ] **MSME / Udyam Certificate (Optional):** Tender fees aur EMD exemption benefits ke liye.

## 🛠️ Step-by-Step Vendor Onboarding Guide on IREPS

Follow karein ye 6 structural steps contractor/supplier account activate karne ke liye:

```
Step 1: Open ireps.gov.in ──> Step 2: Click "New Vendors" ──> Step 3: Connect Class 3 DSC Token
                                                                                │
Step 6: Account Active for Bid <── Step 5: Verification by CRIS <── Step 4: Fill PAN/GST & Form
```

### Step 1: Open Official IREPS Portal
Apne web browser me `https://www.ireps.gov.in` URL enter karke open karein.

### Step 2: "New Vendors / Contractors" button par Click Karein
Home page par left side navigation panel me **New Vendors / Contractors (E-Tender)** link par click karein.

### Step 3: USB DSC Token Connect Karein
Apna Class 3 DSC token system ke USB port me lagayein. System validation popup open hoga, certificate path verify karke **Proceed** select karein.

### Step 4: PAN, GST aur Basic details input karein
Form me business credentials type karein:
* Business Type (Proprietor/Company/Partnership)
* PAN & GST IN Details
* Bank Account specifications (Account No, Bank Name, IFSC code)
* Head office address with state mapping.

### Step 5: Signed Request and Document Upload
Sare scanned documents browse karke upload karein. Form submit karne se pehle portal security dynamic key check karegi. Token PIN enter karke pure page data ko digital sign karein.

### Step 6: Verification and Profile Activation
CRIS verification team aapki request ko verify karegi. 2 se 5 working days ke andar verify status register ho jayega aur login password email par receive hoga.

## 📑 Official Railway Procurement Rules

Indian Railways procurement policies central guidelines par base hoti hain:

* **Indian Railways Financial Code:** Tenders invite aur evaluate karne ke rules set karta hai (Lowest Technically Suitable Bidder ko precedence di jati hai).
* **Purchase Preference Policy (PPP-MII):** Made in India products ko standard pricing matching advantage standard ranges (L1+20%) ke tehat preference milti hai.

## 💡 Expert Tips to Avoid Bid Disqualification

* **Dual Bid Envelope Check:** Hamesha check karein ki bid dynamic template me two-packet system toh nahi hai. Technical documents check box verify karne ke baad hi financial packet (BoQ) submit karein.
* **Keep Bank Details Updated:** IREPS portal auto-credits security deposits directly to registered accounts. Banking details update na hone par EMD refund block ho sakti hai.
* **Check for Corrigendum:** Submission date se 24 ghante pehle portal par tender index check karein taaki kisi change corrigendum ko drop hone se pehle fix kar sakein.

---

## ⚠️ Technical Errors & Solutions on IREPS

1. **"Java Applet Blocked by Security Setting" Error:** Solution: Java configuration setting me Exception Site list me `https://*.ireps.gov.in` insert karein.
2. **"Certificate Path Validation Failed" Error:** Solution: Trusted Root Certificates database me eMudhra/cca key update download karein.
3. **"Token Driver Missing" Status:** System me PKI emBridge application update version run karein.

## ❓ Frequently Asked Questions (FAQs)

### 1. IREPS portal registration ke liye kya fee deni hoti hai?
Nahi, Indian Railways e-Procurement System (IREPS) portal par new vendor/contractor registration bilkul free hai.

### 2. Kya generic e-procurement portal login se IREPS par bid submit ho sakti hai?
Nahi, IREPS ek separate dedicated portal hai. Bidding ke liye aapko ireps.gov.in par naya account banana padega.

### 3. Java Security Block error ko IREPS login me kaise fix karein?
Control Panel me Java Settings open karein, Security tab me jaakar Exception Site List me https://www.ireps.gov.in add karein.

### 4. What is CRIS in IREPS?
CRIS (Centre for Railway Information Systems) Indian Railways ki IT and systems wing hai jo IREPS portal ko run aur monitor karti hai.

### 5. Kya multiple users ek hi registration se bid kar sakte hain?
Haan. Primary user login create hone ke baad portal dashboard se Secondary User profile with specific DSC link kiya ja sakta hai.

### 6. Kya IREPS tenders me EMD bank transfer ke bina submit ho sakti hai?
Udyam registration holder MSMEs ko standard services aur goods purchase me EMD waive-off rules standard relaxation milti hai.

### 7. Railway Tender Search kaise karein?
IREPS homepage par "Search Tenders" feature me zonal railway code select karke keyword search trigger kiya ja sakta hai.

### 8. Registration verify hone me kitne din lagte hain?
Documentation validation ke bad CRIS backend helpdesk typically 2 se 5 working days me approval grant kar deti hai.

### 9. Kya foreign firms IREPS par bid kar sakti hain?
Haan, foreign suppliers specific global tenders me valid global currency documents upload karke participate kar sakte hain.

### 10. Financial Bid/BoQ kya hota hai?
Bill of Quantity (BoQ) pricing sheet hoti hai jise offline update karke e-token configuration signature se save karke submit kiya jata hai.

### 11. Custom specifications challenges kaise raise karein?
Pre-bid clarification stage par system profile se direct representation link submit kiya ja sakta hai.

### 12. IREPS helpline email ID kya hai?
Official support email `helpdesk.eps@ireps.gov.in` hai jo active CRIS technical team handle karti hai.

### 13. Registration ke baad direct e-Auction participate kar sakte hain?
E-Auction module activate karne ke liye profile panel me special auction user permissions map karni hoti hain.

### 14. Password reset validation error solution kya hai?
Browser reset process execute karke secure link click karein, token attach hona validation check ke liye zaroori hai.

### 15. Bid submit hone ke baad response details change ho sakti hain?
Bidding deadline se pehle bid edit/withdraw selection toggle active rehta hai, deadline complete hone par block ho jata hai.
