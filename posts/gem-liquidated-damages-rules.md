# GeM Liquidated Damages (LD) Rules Explained

> [!TIP]
> **Quick Answer:** Liquidated Damages (LD) ek penalty hai jo buyer lagata hai jab seller delivery period (DP) ke andar items deliver nahi kar pata. Ye delay ke hisaab se haftawari (weekly) 0.5% lagti hai.

## At a Glance Dashboard
| Rule | Detail |
| :--- | :--- |
| Weekly Penalty | 0.5% of delayed quantity value |
| Maximum Penalty | 10% of total contract value |
| Calculation Basis | Delayed days beyond Delivery Period |
| Exemption | Force Majeure clause applies |



## 1. Introduction
Sarkari contracts mein time par delivery sabse zaroori hai. Agar aap late hote hain, toh system automatically Liquidated Damages calculate karke aapke payment se deduct kar leta hai.

## 2. Who Should Read This Guide
- Order Fulfillment Teams
- Business Owners
- Finance Executives

## 3. Prerequisites
- Order with a defined Delivery Period (DP)
- Tracking details of the delay

## 4. Required Documents Checklist
- DP Extension Request (if applicable)
- Valid reasons/proof for delay (e.g., transporter strike proof)

## 5. Eligibility Criteria Table
| Delivery Status | LD Applicable? |
| :--- | :--- |
| Within DP | No |
| Beyond DP without extension | Yes |
| Beyond DP with approved extension without LD | No |

> Agar delay bahut zyada ho jata hai aur LD 10% cross kar jata hai, toh buyer contract terminate karke PBG forfeit kar sakta hai.

## 11. Structured FAQs
**Q1: Can LD be waived?**
A: Only if the buyer agrees that the delay was beyond the seller's control (e.g., buyer delayed site readiness).

**Q2: Does GeM deduct LD automatically?**
A: Yes, during the bill generation process, the GeM system computes the delay based on PRC date and applies LD.
