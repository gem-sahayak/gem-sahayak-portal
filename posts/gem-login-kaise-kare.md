Tender submission ke last hour me login error aane se bada nuksan ho sakta hai. Isliye har seller ko **gem login kaise kare** ki sahi prakriya aur troubleshooting steps ki poori jaankari honi chahiye.

## Prerequisites Checklist Before Login

Login screen par jane se pehle in zaroori cheezein check kar lein:

- [ ] **Official Portal URL**: Hamesha `https://gem.gov.in` hi open karein.
- [ ] **Verified User ID**: Aapka official GeM User ID (jo registration ke waqt create hua tha).
- [ ] **Active Password**: Correct password (case-sensitive check karein, Caps Lock off rakhein).
- [ ] **Registered Mobile Phone**: Aadhaar/GeM se linked mobile phone paas me rakhein OTP ke liye.
- [ ] **Updated Web Browser**: Chrome ya Edge ka updated version cache clear karke use karein.

## Step-by-Step Guide: GeM Login Kaise Kare

### Step 1: GeM Official Portal Par Jayein
- **Why**: Fraudulent phishing sites se bachne ke liye official URL zaroori hai.
- **Action**: Browser ke address bar me `gem.gov.in` type karein. Top right bar me **Login** button par click karein.
- **Expected Result**: GeM Sign-in page display hoga jahan User ID enter karne ka box dikhega.
- **Common Mistake**: Google Search ad links ya unofficial portals par click karna.
- **Pro Tip**: Official login page URL me `sso.gem.gov.in` show hota hai.

### Step 2: User ID Enter Karein
- **Why**: System aapke account profile ko identify karta hai.
- **Action**: Input box me apna User ID type karein aur **Submit** par click karein.
- **Expected Result**: Password field aur Captcha challenge screen par appear hoga.
- **Common Mistake**: Email ID ko User ID ki jagah enter kar dena (agar User ID alag hai).
- **Pro Tip**: User ID me space ya extra characters na daalein.

### Step 3: Password Aur Captcha Enter Karein
- **Why**: Security verify karne ke liye password aur automated bots rokne ke liye captcha.
- **Action**: Password text box me apna password enter karein. Captcha image me dikh rahe text ko exact box me type karein.
- **Expected Result**: Authentication complete ho jayegi.
- **Common Mistake**: Caps Lock ON hone ke kaaran wrong password submit hona.
- **Pro Tip**: Agar Captcha readable na ho, toh refresh icon par click karke naya code generate karein.

### Step 4: Submit Par Click Karein Aur Dashboard Access Karein
- **Why**: Primary Seller Dashboard me redirect hone ke liye.
- **Action**: **Login** button par click karein.
- **Expected Result**: Aapka GeM Seller Dashboard open ho jayega jahan active orders, bids, aur catalogue status dikhega.
- **Common Mistake**: Session Timeout indicator ko ignore karna.
- **Pro Tip**: Login hote hi top bar me dikh rahe profile score ko check karein.

## Common Login Errors & Solutions

### 1. "Invalid User ID or Password"
- **Reason**: Caps Lock ON hone se galat password type ho jana ya User ID me typo hona.
- **Solution**: Password ko Notepad me type karke verify karein, phir copy-paste karein. Caps Lock check karein.

### 2. "Captcha Does Not Match"
- **Reason**: Browser me purana image cache rehta hai ya uppercase/lowercase ki galti hona.
- **Solution**: Captcha refresh button dabayein, naya code dhyan se dekhkar type karein.

### 3. "Account Temporarily Locked"
- **Reason**: Continual 5 baar galat password enter karna.
- **Solution**: 24 ghante ka wait karein ya "Forgot Password" link se naya password create karke instant unlock karein.

### 4. "Session Expired / Blank Screen"
- **Reason**: Browser cache me purane session cookies saved rehna.
- **Solution**: Browser history me jaakar **Clear Cache & Cookies** karein, ya Incognito Window (Ctrl+Shift+N) me open karein.

## Official Security Rules & Compliance

- **Two-Factor Authentication (2FA)**: GeM Security Framework 2026 ke tehat sensitive profile edits aur bid submissions par OTP verification compulsary hai.

- **No Shared Credentials**: GTC Clause 2.3 ke anusar Primary User credentials kisi third-party agent ke sath share karna violation mana jata hai.

## Frequently Asked Questions (FAQs)

### Q1. GeM portal login ka official URL kya hai?
GeM portal ka official login URL `https://gem.gov.in` hai. Top bar me "Login" par click karke aap SSO sign-in page par pahunch sakte hain.

### Q2. User ID bhool gaye hain toh recover kaise karein?
Login page par "Forgot User ID" link par click karein. Apni firm ka registered Email ID aur PAN enter karein, User ID aapke email par bhej di jayegi.

### Q3. Password reset karne ka tarika kya hai?
Login screen par "Forgot Password" par click karein. User ID enter karke OTP receive karein aur naya strong password set karein.

### Q4. Multiple failed login attempts ke baad account lock ho gaya hai, kya karein?
Account 5 failed attempts ke baad 24 ghante ke liye lock ho jata hai. Aap "Forgot Password" option se naya password create karke ise turant unlock kar sakte hain.

### Q5. Captcha match nahi ho raha hai, kya karein?
Browser cache clear karein (`Ctrl+F5`) ya Captcha image ke paas bane refresh icon par click karke naya readable Captcha generate karein.

### Q6. Kya mobile OTP ke bina GeM login ho sakta hai?
Normal daily login ke liye password aur captcha kafi hota hai. Lekin password reset ya sensitive details change karne ke liye OTP zaroori hai.

### Q7. Primary User aur Secondary User login me kya farq hai?
Primary User account owner hota hai jiske paas full permissions hoti hain. Secondary User employees hote hain jinhein specific tasks ke liye access diya jata hai.

### Q8. GeM portal login hone par blank screen kyu dikhti hai?
Yeh browser extension conflicts ya purane cache/cookies ki wajah se hota hai. Incognito Window (Private Browsing) me login karke try karein.

### Q9. Password me kaun-kaun se characters hone chahiye?
GeM password me minimum 8 characters, kam se kam ek Uppercase letter, ek Lowercase letter, ek Number, aur ek Special character (`@,#,$`) hona zaroori hai.

### Q10. Kya ek hi computer se do alag GeM accounts me login kar sakte hain?
Haan, lekin ek samay par do accounts me login karne ke liye do alag browsers (Chrome aur Edge) ya Incognito mode ka use karein.

### Q11. "Session Timeout" error baar-baar kyu aata hai?
GeM portal security reasons se 15-20 minute tak inactive rehne par session automatically expire kar deta hai. Periodic activity karte rahein.

### Q12. Shared computer par login karte waqt kya savdhani bartein?
Work poora hone ke baad hamesha "Logout" button par click karein aur browser window close karein. "Remember Password" kabhi click na karein.
