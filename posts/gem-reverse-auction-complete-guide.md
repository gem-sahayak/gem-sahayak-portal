# GeM Reverse Auction Complete Guide 2024: Kaise Participate Karein aur Jeetein

> [!TIP]
> **Quick Answer:** GeM Reverse Auction (RA) ek dynamic competitive bidding process hai jahan sellers real-time mein apna price reduce (decrement) karte hain taaki L1 position secure kar sakein.

## At a Glance Dashboard
| Feature | Details |
| :--- | :--- |
| Process Type | Reverse Bidding |
| Decrement Rule | 0.1% to 10% of Current L1 |
| Eligibility | Technically Qualified Bidders |
| Typical Duration | 2 to 7 Days |



## 1. Introduction
Reverse Auction (RA) GeM par ek powerful mechanism hai buyers ke liye cost save karne ka, aur sellers ke liye L1 position win karne ka. Jab technical evaluation ho jata hai, tab buyers RA initiate kar sakte hain. Is guide mein hum Reverse Auction ka complete process samjhenge.
