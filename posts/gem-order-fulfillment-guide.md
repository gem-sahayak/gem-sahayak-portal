# GeM Order Fulfillment Guide: Generation to Dispatch

> [!TIP]
> **Quick Answer:** Contract milne ke baad, seller ko items deliver karne ke liye GeM portal par Invoice generate karni hoti hai, e-Way bill upload karna hota hai aur dispatch proof submit karna hota hai.

## At a Glance Dashboard
| Action | Detail |
| :--- | :--- |
| Acceptance Window | Usually 48 hours |
| Invoice Creation | Pre-dispatch |
| Dispatch Proof | LR/RR/Courier Receipt |
| Delivery Date | Strictly as per Contract |



## 1. Introduction
GeM par Order fulfill karna offline kaam se thoda alag hai. Yahan har step digital trail banata hai. Agar aapne online details theek se update nahi ki, toh consignee receive nahi kar payega.

## 2. Who Should Read This Guide
- Logistics and Dispatch Managers
- GeM Sellers
- Account Executives

## 3. Prerequisites
- Order in 'Accepted' state
- Ready stock for packaging
- Authorized transporter

## 4. Required Documents Checklist
- Tax Invoice (GST)
- E-way bill (if value > 50k)
- Manufacturer Warranty Card (if applicable)

## 5. Eligibility Criteria Table
| Action | Requirement |
| :--- | :--- |
| Generate Invoice | Must have accepted the order |
| Update Dispatch | Must have generated the invoice |

## 11. Structured FAQs
**Q1: Can I dispatch multiple shipments for one order?**
A: Yes, partial dispatch is allowed if permitted in the contract.

**Q2: What is dispatch proof?**
A: A valid Lorry Receipt (LR), Railway Receipt (RR), or Courier tracking slip.
