# GeM Contract Performance Security (ePBG) Guide

> [!TIP]
> **Quick Answer:** Contract award hone ke baad, seller ko contract ki performance guarantee dene ke liye ePBG submit karni hoti hai. Yeh generally contract value ka 3% to 10% hota hai.

## At a Glance Dashboard
| Feature | Details |
| :--- | :--- |
| Guarantee Amount | 3% to 10% of Order Value |
| Submission Time | Usually 15 days from Contract Date |
| Validity | Contract duration + 60 days |
| Exemption | No complete exemption (some waivers may apply) |



## 1. Introduction
Order milna pehla step hai. Order ko successfully execute karne ki guarantee government ko ePBG ke through di jaati hai. Is article mein hum dekhenge ki ePBG kaise banwayein aur GeM par kaise upload karein.

## 2. Who Should Read This Guide
- Successful Bidders
- MSME Owners
- Financial Advisors

## 3. Prerequisites
- Awarded GeM Contract
- Good relationship with an issuing Bank

## 4. Required Documents Checklist
- Bank Guarantee Format (provided in contract)
- Bank's SFMS Confirmation details

## 5. Eligibility Criteria Table
| Criteria | Need ePBG? |
| :--- | :--- |

| Contract Value > Rs. 5 Lakhs (if stipulated) | Yes |

## 11. Structured FAQs
**Q1: What happens if I don't submit ePBG?**
A: Contract can be terminated and incident raised.

**Q2: Are MSMEs exempt from ePBG?**
A: No, unlike EMD, PBG is generally required from all, though the percentage might be lower.
