GeM seller account me log in karte waqt credentials misplace hone par portal access interrupt ho jata hai.

> 📌 **Answer Capsule**  
> **In one line:** GeM account access is recovered using the Forgot Password or Forgot User ID features via registered mobile and email OTP authentication.  
> **What matters:** Password resets require User ID and OTP; User ID recovery relies on tax/registration details; registered contact updates require helpdesk documentation if access is lost.  
> **What can change:** Exact portal UI labels, recovery screens, and lockout timers may change with portal software updates.

## 1. Account Recovery Workflow Options

```
Option 1: Password Reset -> Use "Forgot Password" + User ID + OTP.
Option 2: User ID Recovery -> Use "Forgot User ID" + PAN / GSTIN.
Option 3: Mobile/Email Unreachable -> Submit Helpdesk Request with Organization Authorization Documents.
```
