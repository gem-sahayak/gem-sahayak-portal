## Introduction

Namaste Dosto! GeM (Government e Marketplace) portal par aapka mobile number aur email address sirf contact details nahi hain, balki yeh aapke business key security aur control ki chabi hain. Jab bhi aap koi bid submit karte hain, caution money refund request daalte hain, ya catalogue list karte hain, GeM direct OTP verification karta hai.

Lekin kai baar aisa hota hai ki primary user ka registered mobile number kho jata hai, deactive ho jata hai ya phir authorized signatory badal jata hai. Aise me email aur mobile number update karna zaroori ho jata hai taaki aap bidding process me bina kisi rukawat ke participate kar sakein.

Is detailed guide me hum aapko step-by-step process batayenge ki kaise aap apne GeM profile me mobile aur email update kar sakte hain, Aadhaar OTP validation kaise kaam karta hai aur Authorized Signatory verify karne ke kya rules hain.

Yeh guide un sabhi logon ke liye hai jo GeM portal par business operate karte hain:
- **Proprietors & Business Owners**: Jo apna personal contact information update karna chahte hain.
- **Partners & Directors**: Jo company operations ke transfer ya restructuring ke dauran details change karna chahte hain.
- **Authorized Signatory / Staff**: Jinhe official communications receive karne ke liye credentials update karne hain.
- **Sellers facing OTP Issues**: Jinhe bidding ya password reset ke waqt registered number par OTP nahi mil raha.

## Prerequisites Before Changing Details

Profile change process shuru karne se pehle in zaroori cheezon ka dhyan rakhein:
- **Primary User Access**: Aapke paas main seller account ka active login credential (User ID & Password) hona chahiye.
- **Aadhaar Linked Mobile**: Naya ya updated mobile number aapke Aadhaar Card se pehle se link hona chahiye kyunki UIDAI portal se verification kiya jata hai.
- **Email Access**: Naya email address active aur accessible hona chahiye taaki aap instant verification link aur OTP handle kar sakein.
- **Stable Network**: Aadhaar OTP verification ke liye system fast internet connection demand karta hai taaki session timeout na ho.

## Step-by-Step Guide: Email & Mobile Change Process

Sellers ke liye GeM profile update process me email aur mobile number badalne ke main 5 steps hote hain. Ise aasan Hinglish me samjhein:

### Step 1: GeM Portal Par Login Karein
- **Action**: Sabse pehle `gem.gov.in` par jayein aur primary user account se log in karein.
- **Expected Result**: Home dashboard open hoga.
- **Pro Tip**: Hamesha primary user login hi select karein, kyuki secondary user ke paas email/mobile change ke options nahi hote.

### Step 2: Profile Settings Section Me Jayein
- **Action**: Top right corner me apne profile icon ya user name par click karein aur **My Profile** option par click karein.
- **Expected Result**: Profile page open ho jayega jahan key sections (PAN, Company, Personal Settings) show honge.

### Step 3: Mobile / Email Modify Option Choose Karein
- **Action**: Menu bar me **Personal Settings** tab par click karein. Email/Mobile edit option par click karein.
- **Expected Result**: Current email aur mobile number show honge, aur side me 'Edit' ya 'Update' text display hoga.

### Step 4: Aadhaar OTP Verification Complete Karein
- **Action**: Naya contact details fill karke **Verify Aadhaar** par click karein. Registered Authorized Signatory ka Aadhaar enter karein.
- **Expected Result**: UIDAI server se link number par ek 6-digit Aadhaar OTP jayega. Use input box me fill karke verify karein.
- **Common Mistake**: Agar naya mobile Aadhaar se linked nahi hai toh OTP purane number par hi jayega ya call block ho jayegi.

### Step 5: New Mobile & Email Par OTP Verify Karein
- **Action**: Aadhaar confirm hote hi system naya number aur email save karne se pehle dobara ek transaction OTP bhejega.
- **Expected Result**: Naye mobile par SMS OTP aur naye email par Verification code aayega. Dono ko screen par enter karke **Save Changes** click karein.
- **Result**: Profile page update ho jayega aur confirmation message show hoga.

## Frequently Asked Questions (FAQs)

### Q1. Kya primary user ka email aur mobile number bina login kiye badal sakte hain?
Nahi, security reasons ki wajah se profile settings ko modify karne ke liye primary user dashboard me login karna compulsory hai. Agar aap password bhool gaye hain toh pehle 'Forgot Password' link use karein.

### Q2. Agar primary user company chhod gaya hai aur password nahi pata, toh details kaise badlein?
Aise cases me, naya authorized signatory registered official email ID ke through password recover kar sakta hai. Agar email bhi inaccessible hai, toh GeM Helpdesk par official authorization and board resolution documents mail karke reset ki request daalni padegi.

### Q3. GeM mobile update karte waqt "Aadhaar Name Mismatch" error kyu aata hai?
Yeh error tab aata hai jab aapke GeM profile me primary user ka naam aur Aadhaar Card par likha naam bilkul exact match nahi karte. spelling ki choti si galti bhi mismatch error generate karti hai.

### Q4. Aadhaar OTP registered mobile number par nahi aa raha hai, kya karein?
Aadhaar OTP direct UIDAI server se aata hai. Check karein ki aapka mobile active hai aur usme SMS limits block nahi hain. Agar issue bana rehta hai, toh thodi der baad try karein ya local UIDAI center se contact number update status check karein.

### Q5. New mobile number par OTP kitni der me expire hota hai?
GeM portal par verification ke dauran aane wale OTPs standard 10 minutes ke liye valid hote hain. Uske baad link expire ho jata hai aur refresh karke OTP generate karna hota hai.

### Q6. Kya hum ek hi mobile number do alag GeM seller accounts me link kar sakte hain?
Nahi, GeM portal standard guidelines ke tehat ek registered primary user account me unique mobile number aur unique email ID hi allow karta hai taaki security and compliance maintain rahe.

### Q7. Secondary User ka mobile change kaise hota hai? Kya use bhi Aadhaar OTP chahiye?
Secondary user ka mobile change Primary User dashboard se hota hai. Primary user 'Manage Users' me jaakar details update kar sakte hain. Isme secondary user ka Aadhaar verify hona mandatory hai.

### Q8. E-sign verification failed error kaise solve karein?
Aadhaar e-Sign fail hone ka main reason network lag ya Aadhaar database mismatch hota hai. Chrome browser use karein, cookies and pop-ups toggle on rakhein aur transaction slow networks par na karein.

### Q9. Mobile change karne ke baad profile approval me kitna time lagta hai?
Aadhaar-OTP based profile change updates instant update ho jate hain. System e-sign confirmation submit hote hi automatic database record update kar deta hai.

### Q10. Authorized Signatory change karne ke liye authorization letter ka format kahan se milega?
GeM portal ke resources panel par document templates milte hain. Aap apne letterhead par "Authority Letter for GeM" draft karke board of directors ya partners ke sign aur stamp ke sath upload kar sakte hain.

### Q11. GeM account me email change hone ke baad purane notifications kahan dikhenge?
Email change karne par purane emails recover nahi hote. Lekin aapke GeM Seller Dashboard ke "Inbox/Bell Icon" me historical messages, bids alerts, aur notices hamesha saved rehte hain.

### Q12. Kya hum NRI primary user ka foreign mobile number update kar sakte hain?
GeM portal Indian country codes (+91) ko hi support karta hai validation ke liye. NRI users ke paas verified Indian mobile number hona chahiye jo unke Aadhaar se linked ho.

### Q13. Mobile number update block hone par support ticket kaise raise karein?
Aap helpdesk page par jaakar screen screenshot attach karein aur "Profile Updates -> Contact Change Issue" category select karke ticket raise kar sakte hain.

### Q14. Portal par change request select karne ke baad mobile number change submit nahi ho raha, kya reason ho sakta hai?
Aapka profile completion status agar 100% nahi hai ya caution money update pending hai, toh portal modifications lock kar deta hai. Pehle standard checks clean karein, phir contact detail change karein.

### Q15. Company change hone par kya hum new primary user add kar sakte hain ya register naya karna padega?
Agar PAN number badal raha hai (jaise Proprietorship se Private Limited conversion), toh aapko GeM par naya register account banana hoga. Primary user change sirf existing entity ke same identity details me updates ke liye valid hai.
