Government e-Marketplace (GeM) portal par organization account setup aur operations manage karte waqt **Primary User** aur **Secondary User** ke roles aur permissions ko samajhna bohot zaroori hai.

> 📌 **Answer Capsule**  
> **In one line:** Primary User holds master administrative ownership on GeM, while Secondary Users are delegated operational sub-roles.  
> **What matters:** Primary User manages user creation, profile updates, and key credentials; Secondary Users handle assigned tasks like bid submission or order processing; account ownership stays with the organization.  
> **What can change:** Exact portal re-assignment procedures for employee exits depend on GeM helpdesk verification requirements and current administrative policies.

## 1. What Is a Primary User on GeM?

Primary User organization ka official master administrative account user hota hai jiske credentials aur verification ke sath organization on-board hoti hai.

### Primary User Key Functions:
- Organization master profile (PAN, GSTIN, Bank Details) manage karna.
- Secondary Users create, modify, ya deactivate karna.
- Caution money deposits aur master legal undertakings submit karna.

---

## 2. What Is a Secondary User on GeM?

Secondary Users Primary User dwara create kiye gaye team members hote hain jinhe specific functional responsibilities assigned hoti hain.

### Common Operational Roles:
- **Catalog Manager:** Product aur Service catalog listings handle karta hai.
- **Bid Manager:** Active tenders search aur bid submission perform karta hai.
- **Order Manager:** Order acceptances, CRAC tracking, aur invoice processing dekhta hai.

---

## 3. Primary User vs Secondary User Role Matrix

| Attribute / Function | Primary User | Secondary User |
| :--- | :--- | :--- |
| **Account Ownership** | Master Administrative Owner | Delegated Operational Staff |
| **Account Creation** | Direct Portal Registration | Created by Primary User |
| **User Management** | Create / Edit / Deactivate Secondary Users | No user creation permissions |
| **Master Profile Edits** | Full Access | Restricted / Read-Only |
| **Operational Execution** | Full Access | Subject to Assigned Sub-Roles |

---

## 4. Primary User Transfer & Administrative Best Practices

Jab company me Key Managerial Personnel (KMP) ya Primary User handle karne wala employee change hota hai, tab portal continuity maintain rakhne ke liye administrative procedures follow kiye jaate hain:
- Company letterhead par official authorization letter aur Board Resolution prepare karein.
- Helpdesk support channels ke dwara user update request process karein as per applicable GeM verification guidelines.
- Unauthorized access prevent karne ke liye exited staff ki Secondary IDs instantly deactivate karein.

## Frequently Asked Questions

### 1. Can a Secondary User edit company bank details?
Nahi, sensitive master profile settings like bank account, PAN, aur GSTIN updates Primary User authorization ke under hote hain.
