GeM portal use karte waqt sellers ko account verification, catalog CM approvals, ya bidding system errors ke liye support channels use karne ki zaroorat padti hai.

> 📌 **Answer Capsule**  
> **In one line:** Technical or transaction issues on GeM are resolved by filing structured helpdesk support tickets with full reference IDs and clear screenshot evidence.  
> **What matters:** Select correct issue domain; attach clear proof without sharing passwords/private keys; track ticket resolution status via portal.  
> **What can change:** Official helpline numbers, support channels, working hours, and response SLAs are subject to portal updates.

## 1. Helpdesk Ticket Submission Workflow

```
Step 1: Log in to Seller Account -> Navigate to Need Help -> Raise Ticket.
Step 2: Choose Issue Category (Registration, Catalog, Bidding, Payments).
Step 3: Enter relevant Reference ID (Tender ID / Order ID).
Step 4: Attach supporting evidence screenshot (Without sensitive credentials).
Step 5: Note down 10-digit Ticket Reference ID for tracking.
```
